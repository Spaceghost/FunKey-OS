# Optional freeware game pack

The freeware collection is user data, not part of FunKey OS. It is released
separately and changes only when the collection itself changes. Installing a
firmware update does not remove games already stored on the shared partition.

Current pack:

- File: `FunKey-freeware-games-1a0fdac6852bdcb079d193d0aa5b29d138493e4fc2527bdb1fe0293d75268908.zip`
- SHA-256: `1a0fdac6852bdcb079d193d0aa5b29d138493e4fc2527bdb1fe0293d75268908`
- Release tag: `freeware-games-1a0fdac6852b`

To install it, mount the RG Nano shared partition over USB and extract the ZIP
directly into the top level of that partition. Its platform directories merge
with the existing `Game Boy`, `NES`, `PICO-8`, and other game directories.
Existing files are not required to be overwritten.

The collection includes homebrew and shareware for several systems. Quake II,
Quake, and the Game Boy Advance selection account for most of its size. See the
release notes for the complete inventory and redistribution caveats.
